# Archived launchers

These launchers are kept only for legacy/debug access and are not part of the normal RuneScape Two workflow.

Canonical root launchers are documented in `docs/TOOLING.md`.

Archived here:
- `Start Colour Tester.bat`
- `Start Definition Tester.bat`
- `Start Image Tester.bat`
- `Start Tester Hub.bat`

The underlying Python modules are intentionally left in place for now. This cleanup removes launcher clutter without risking hidden dependencies. Old tools can be removed later only after their functionality is fully covered by the canonical tools.
